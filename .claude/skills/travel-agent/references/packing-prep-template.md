# Packing & Prep Template

The packing list is **tailored** - to weather, activities, length, and destination - not a generic checklist. The prep checklist captures the boring-but-critical pre-trip items that people forget when they're excited about the trip itself.

---

## Packing List - Structure

Build the list in **layers**, not categories like "shirts." Layers map to *what the traveler will actually use,* and they catch the gaps better.

### Layer 1: Travel-Day Outfit

What you wear on the plane / train / in the car. Comfortable, layered, easy through security.

### Layer 2: Daily Wear

Computed: number of days × climate-appropriate × wash/laundry plan.
- 7 days, hot climate, laundry available → 4 sets
- 7 days, hot climate, no laundry → 7 sets
- 7 days, cold layered climate → 4 base + 2 mid-layers + 1 outer

### Layer 3: One-Off / Activity Wear

Anything specific to a planned anchor:
- Dinner at a dress-code restaurant - collared shirt or dress
- Hike - trail shoes, daypack, layered top
- Beach day - swim, cover-up, reef-safe sunscreen
- Religious site - covered shoulders, long pants/skirt
- Cold-weather adventure - base layer, insulating mid, shell
- Black-tie event - packable dress / suit

### Layer 4: Footwear

- One walking pair (already broken in)
- One nicer pair if dinners require it
- One activity-specific pair if relevant (hiking, sand, snow)
- Sandals if pool / beach / hot

### Layer 5: Tech and Documents

- Passport + photocopy + cloud backup
- Driver's license if renting a car
- Credit cards (at least 2 networks - Visa + AmEx, etc.)
- Cash in destination currency for arrival expenses
- Phone + charger + backup battery + adapter
- eSIM activated or roaming plan confirmed
- Camera (if relevant) + spare battery + memory card
- Headphones (noise-canceling for the flight)
- Laptop (only if working)
- Cables for everything packed

### Layer 6: Toiletries / Health

- Travel-size everything (TSA / hand-luggage rules)
- Prescription medications + 2 days extra
- OTC kit: pain reliever, anti-diarrheal, antihistamine, motion sickness
- Sunscreen (reef-safe if relevant)
- Insect repellent (DEET / picaridin / lemon eucalyptus depending on destination)
- Bandaids + blister care
- Mini hand sanitizer

### Layer 7: Trip-Specific Smalls

- Reusable water bottle
- Daypack / crossbody for daily use
- Packing cubes
- Quick-dry travel towel (if hostels / outdoor)
- Padlock (if hostels / lockers)
- Earplugs + sleep mask
- Compression socks for long flights

## Climate-Specific Add-Ons

| Climate | Don't forget |
|---|---|
| Hot, humid | Quick-dry fabrics, light long-sleeve for sun protection, electrolyte tablets, breathable shoes |
| Hot, dry | High-SPF, lip balm with SPF, scarf for sun, hat with chin strap |
| Cold, dry | Moisturizer, lip balm, hand cream, hat that covers ears |
| Cold, wet | Waterproof shell, waterproof shoes, fast-dry layers, packable umbrella |
| High altitude | Sunscreen (UV is stronger), water bottle, headache meds, slow-pacing mindset |
| Tropical | Reef-safe sunscreen, insect repellent, anti-mosquito clothing if malaria zone |
| Desert | Layers (cold at night), wide-brim hat, electrolytes |
| Ski / snow | Goggles, base layers, glove liners, hand warmers |

---

## Activity-Specific Add-Ons

- **Beach / pool:** swim, cover-up, flip-flops, dry bag, reef-safe SPF
- **Hiking:** trail shoes, daypack, hydration, trekking poles if rentals not available
- **Skiing:** lift pass holder, helmet (rent or pack), neck gaiter
- **Diving / snorkeling:** mask if you have one (rentals are hit or miss), rash guard
- **Photography trip:** tripod (travel size), cleaning kit, more SD cards than you think
- **Religious sites:** covered shoulders, long pants/skirt, scarf
- **Black-tie event:** the actual outfit, plus the shoes that go with it
- **Wedding-as-destination-trip:** the ceremony outfit, plus the flat-pack second pair of nicer shoes

## Prep Checklist - Pre-Trip Actions

Compute deadlines based on departure date. List in order of when they need to happen.

### 60+ days before

- [ ] **Passport check** - at least 6 months validity remaining beyond return date
- [ ] **Visa requirements** - research, apply if needed (some take 60+ days)
- [ ] **Vaccinations** - yellow fever needs 10+ days, multi-dose vaccines need weeks
- [ ] **Travel insurance** - buy now, before any trip-cost is non-refundable
- [ ] **Major reservations** - hotels, signature restaurants, lottery experiences

### 30 days before

- [ ] **Driver's license check** - IDP if needed
- [ ] **Credit card foreign-transaction-fee audit** - apply for fee-free card if needed (4–6 weeks for some)
- [ ] **Notify bank of travel** (some banks still require this)
- [ ] **Pet sitter / boarding** booked
- [ ] **House sitter / mail hold** scheduled
- [ ] **Pre-paid currency or cash** for arrival expenses (some destinations are cash-only at airport)
- [ ] **Frequent-flyer numbers** added to all bookings

### 14 days before

- [ ] **eSIM purchased / roaming plan activated**
- [ ] **Offline maps downloaded** (Google Maps regions, Maps.me for off-grid)
- [ ] **Translation app** with offline pack downloaded
- [ ] **Emergency contacts list** prepared (digital + paper copy)
- [ ] **Embassy / consulate info** for the destination
- [ ] **Flight check-in app** installed
- [ ] **TSA PreCheck / Global Entry / Mobile Passport Control** confirmed working
- [ ] **Hotel addresses** saved in native script (e.g., Japanese / Mandarin / Cyrillic) for taxi handoff

### 7 days before

- [ ] **Final packing list** review against weather forecast
- [ ] **Document copies** - passport + visa + insurance + key bookings to cloud
- [ ] **Document copies on paper** - kept separate from passport, in case of theft
- [ ] **Print or save offline:** boarding passes, hotel confirmations, train tickets, restaurant reservations
- [ ] **Charge everything** the night before
- [ ] **Empty fridge** of anything that'll go bad
- [ ] **Final mail / package check**

### 24 hours before

- [ ] **Web check-in for first flight**
- [ ] **Final weather check** - adjust packing
- [ ] **Confirm airport transfer time** (uber/taxi or self-drive)
- [ ] **Pack passport** - wallet, phone, charger, snack - in carry-on
- [ ] **Hydrate, sleep**

### Day of departure

- [ ] **Hotel address saved offline** in destination
- [ ] **First-night reservation noted** somewhere accessible offline
- [ ] **Cash + card on person** (not in checked bag)

## Emergency Contacts Block

For the PDF deliverable, include:
- **Embassy / consulate** in the destination - address, phone, after-hours emergency line
- **Insurance provider** - 24-hour emergency line + policy number
- **Credit card lost/stolen lines** - international collect-call numbers
- **Home emergency contact** - one person back home who knows the itinerary
- **Local emergency numbers** - police, ambulance, fire (varies - 112 in EU, 110 in Japan, 999 in UK)
- **Hotel(s) phone numbers**
- **Pre-arranged transfer driver's contact** (if applicable)

---

## Format for the PDF Deliverable

Two pages:
1. **Packing list** - laid out in layers, with a checkbox per item, weather-tailored
2. **Prep checklist** - counted-down by days-to-departure, with checkboxes
3. **Emergency contacts block** - a single boxed page, formatted for the user to print and keep with their passport

The prep checklist is the page that actually gets used the most pre-trip. Make it scannable, with deadlines visible.
